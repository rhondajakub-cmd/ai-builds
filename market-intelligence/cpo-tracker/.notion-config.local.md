# Notion configuration for cpo-tracker

This file holds credentials for writing to your Notion AI Operations Registry. If you don't fill in the values, the skill will write only to the Desktop log and skip Notion.

## How to fill this in (one-time setup, ~5 min)

1. Go to https://www.notion.so/profile/integrations
2. Click "New integration" → name it "CPO Tracker" → workspace = your workspace → submit
3. Copy the "Internal Integration Secret" (starts with `ntn_` or `secret_`) → paste it as `NOTION_TOKEN` above
4. Open your AI Operations Registry page in Notion: https://www.notion.so/AI-Operations-Registry-Template-648b16bb617b82a4aa488189ba97da70
5. Decide where CPO placements should live. Two paths:
   - **A)** Use an existing database in the registry that fits — open it, click `•••` top-right → "Connections" → add the "CPO Tracker" integration → copy the database URL → the database ID is the 32-char string in the URL → paste as `DATABASE_ID` above
   - **B)** Create a new "CPO Placements" database — see schema below — then do the connection + ID steps above

## Expected database schema

The skill writes pages with these properties. Property names must match (case-sensitive):

| Property | Type | Notes |
|---|---|---|
| Name | Title | The person's name |
| Role | Text | "Chief People Officer", "Head of People", etc. |
| Company | Text | Company name |
| Date | Date | When they started the role (best estimate) |
| Location | Select | Options: NYC, SF Bay, Remote, Other |
| Industry | Text | "Fintech", "AI", etc. (from LinkedIn industry field) |
| Source URL | URL | Link to the announcement post or press release |
| Profile URL | URL | LinkedIn profile URL |
| Firm Tag | Text | "Placed via Plenty Search" or blank |
| Source Type | Select | Options: LinkedIn Post, LinkedIn Profile, Web, Press Release |

If your existing database has different property names, edit the SKILL.md `curl` payload to match.

## Verifying it works

After filling in `NOTION_TOKEN` and `DATABASE_ID`:

```bash
curl -s https://api.notion.com/v1/databases/$DATABASE_ID \
  -H "Authorization: Bearer $NOTION_TOKEN" \
  -H "Notion-Version: 2022-06-28" | head -30
```

If you get a JSON response with the database title, you're good. If you get `"object": "error"`, the integration isn't shared with the database or the token is wrong.
