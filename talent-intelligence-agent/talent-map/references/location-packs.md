# Location packs

Extra sources to use only when the search location matches. Every search uses the general sources in SKILL.md; these are additions.

## New York
- Tech:NYC member list and NY Snapshot
- NYC Startups Airtable (active jobs board)
- Built In NYC
- Decoded Futures member orgs

## San Francisco Bay Area
- Built In SF

## Boston
- Built In Boston

## Other metros
- Built In publishes city editions for Chicago, Seattle, Austin, Colorado, and LA. Use the matching edition.
- Search "[metro] tech ecosystem report [year]" and "[metro] startup directory" for a local equivalent of Tech:NYC.

## Remote or national
- Skip metro sources. Size the pool at the country level and say so.

Add a pack when a search in a new location turns up a source worth reusing.
